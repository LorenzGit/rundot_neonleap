# NEONLEAP — design canon

> One tap. One city. No brakes.

NEONLEAP is a Canabalt-lineage one-touch auto-runner for RUN.world. A courier
sprints rightward across an endless, rain-slick neon skyline at night. The
city scrolls faster and faster; the only verb is **jump**. Gaps kill. Rooftop
clutter only staggers you. Score comes from distance, pickups, and near-misses
amplified by a flow multiplier that punishes hesitation, and five powerups
turn survival into set-pieces. Every death lands on a results screen one tap
away from the next run.

This file is canon for content and numbers. Code follows this document; when
they disagree, fix the code or update this file in the same change.

## 1. Pillars

1. **One finger, full depth.** Tap = jump, hold = higher. Every piece of
   mastery — coyote jumps, near-miss lines, powerup routing — sits inside that
   single input. No buttons, no sticks, no menus mid-run.
2. **The run is the reward.** Runs last 30–180 seconds and death is cheap:
   results to restart is one tap and under two seconds. Every system (flow,
   near-miss, stumble) exists to make "one more run" irresistible.
3. **Readable at 900 u/s.** At top speed the player has ~400 ms to read a
   gap. The world is a dark silhouette stage with neon edge-lighting; the
   runner is the brightest thing on screen. If a death feels unfair, the
   presentation failed, not the player.
4. **Everything procedural — except the score.** Every texture, skyline,
   particle, glyph, and sound effect is generated by the game's own code at
   boot; no image or font ships. The one bundled asset is the owner-supplied
   music track (see §13).

## 2. Stage and coordinates

- Design resolution **1280×720**, landscape only. Camera is fixed on the
  runner: runner x sits at **26% of stage width**; the world scrolls left.
- Ground band: rooftop tops live between **y = 260** (highest) and
  **y = 560** (lowest). Stage floor / kill plane is **y = 760** (below the
  visible frame; falling past it is death).
- Safe area: HUD honors RUN insets; nothing interactive sits in the outer
  24 px of the design stage.

## 3. The runner

| Property | Value |
| --- | --- |
| Body | 26×58 px silhouette, feet at position |
| Run speed `v` | starts **380 u/s**, ramps continuously to **920 u/s** (see §7) |
| Jump impulse | **950 u/s** vertical |
| Gravity (rising, holding) | **1450 u/s²** |
| Gravity (rising, released) | **3100 u/s²** |
| Gravity (falling) | **2600 u/s²** |
| Terminal fall speed | **1400 u/s** |
| Coyote time | **0.09 s** |
| Jump buffer | **0.12 s** |
| Max hold-extended airtime | ~1.02 s (tune-verified by `npm run balance`) |

Variable jump height comes from the gravity split: a released jump cuts
upward velocity short (short hop ~140 px apex), a held jump carries to the
full ~310 px apex. This is the entire skill ceiling of the input.

The runner never slows voluntarily. Landing on the very edge of a rooftop
(front 10 px) triggers a micro stumble-free "edge save" spark — purely
cosmetic, but it sells speed.

## 4. Death and stumble

- **Gaps kill.** Falling below the kill plane ends the run. So does a
  full-speed face-plant into a **billboard** (the only lethal obstacle,
  always ≥ 110 px tall, always signposted with amber hazard stripes).
- **Clutter staggers.** Vents, AC units, and antennas (28–96 px) cause a
  **stumble**: speed × **0.45**, flow multiplier resets to ×1, **1.2 s**
  invulnerability, the obstacle shatters. Three stumbles in one run do
  nothing extra — the lost speed and flow is the punishment.
- Stumble is always survivable; only gaps and billboards end runs. Death
  must always trace to a player-visible cause.

## 5. Flow multiplier

Flow is the addiction engine. It rewards *clean* play, not just survival.

- Flow tiers: **×1, ×2, ×3, ×4**. Flow points fill the tier:
  - rooftop landing without stumbling: **+1**
  - near-miss (clearing an obstacle by ≤ 24 px vertical clearance): **+2**
  - pickup chain of 5+ without a stumble: **+2**
  - billboard smash during OVERDRIVE: **+1**
- Tier up at **6 / 14 / 26** points (×2 / ×3 / ×4). Tier holds for the whole
  run until a stumble.
- **Stumble → ×1 and 0 points.** Falling to a lower rooftop does not break
  flow; only stumbles do.
- Flow multiplies **all** score events (distance ticks, pickups, near-miss
  bonuses, smashes).

## 6. Score and pickups

| Event | Base score |
| --- | --- |
| Distance | 1 pt per 10 u travelled (i.e. ~38–92 pts/s by speed) |
| Cell pickup | 10 |
| Near-miss | 25 |
| Obstacle smash (OVERDRIVE) | 15 |
| Billboard smash (OVERDRIVE) | 40 |

**Cells** are both score pickups and the soft currency: every cell picked up
is banked (persisted) and spendable in the Upgrade Bay. Cells spawn in
choreographed lines of 4–9 that trace good jump arcs — following a cell line
is always a survivable line.

## 7. Speed and difficulty ramp

Difficulty is a function of distance, in **tiers of 250 m**:

Speed itself climbs smoothly, never in steps:
`v(d) = min(920, 380 + 0.28 × d)` with d in metres — 380 u/s off the line,
+70 u/s every 250 m, capped at 920 u/s around 1.9 km. Tiers
(`tier = floor(d / 250)`) remain progress milestones for music layers,
missions, and the HUD's pace callouts. Generator knobs key off **pace** —
the current speed mapped back onto the 0–16 scale — so content difficulty
always arrives with the speed it was tuned for, whatever the ramp's slope.

Generator constraints scale with tier (see §8 for the generator):

| Knob | Tier 0 | Tier 8 | Tier 16 |
| --- | --- | --- | --- |
| Gap width | 60–140 u | 140–260 u | 200–340 u |
| Gap cap | ≤ 0.55 × max jump range at current speed | 0.62× | 0.68× |
| Rooftop length | 380–900 u | 400–800 u | 520–880 u |
| Roof height step | ±60 u | ±100 u | ±120 u |
| Obstacle chance / roof | 0.35 | 0.6 | 0.8 |
| Billboard chance | 0 | 0.10 | 0.18 |

The gap MINIMUM climbs steeply with the tier because so does the smallest
possible jump: at 900 u/s even a tapped hop flies ~570 u, so a small gap in
front of a short roof would be a trap where every jump overflies the landing.
High speed means big committed gaps and long roofs, never stub hops — the
balance sweep proved the earlier (120 u min gap / 240 u min roof / ±160 step)
extremes unlandable and this table carries the corrected numbers.

The gap cap is the fairness contract: a held jump at current speed always
clears the widest gap with margin, and `npm run simulate` proves it by
replaying generated track with a planner bot that only uses the player's own
verbs (variable-hold jumps, walk-off drops, roof-skips).

## 8. Track generator

Deterministic from the run seed (`NoiseRandom` — no `Math.random()` in game
logic). The generator emits a stream of **segments** ahead of the camera and
recycles behind it:

1. **Rooftop** — length and top-y per §7. Consecutive roofs differ in height
   by the tier's step; drops feel fast, rises read as climbs.
2. **Gap** — width per §7, capped by the fairness contract.
3. **Clutter** — 0–2 obstacles per roof by tier chance. Never within 140 u
   of either roof edge (landing zones stay clean). A billboard roof extends
   past the tier's length cap when needed: the lethal obstacle always leaves
   room to rise over it after the gap (a lead-in scaled by tier speed) and to
   LAND after the leap that clears it (a tail of 0.9 × flat jump reach).
4. **Cell line** — 55% of roofs and every gap ≥ 180 u gets an arc/line of
   cells tracing the jump that clears it.
5. **Powerup pedestal** — every **190–320 m** of travel (base rate; upgraded
   by LUCKY COIL), a pedestal on a flat roof section carries one powerup.
   Kind is rolled from the run seed with equal weights; no kind repeats
   twice in a row.

The first 600 u of every run are a guaranteed clean flat roof (the "runway")
so every run starts with stable footing.

## 9. Powerups

Five powerups, each readable at a glance by color and icon, each with its
own activation stinger and screen treatment. Durations are extended by the
CAPACITOR upgrade; spawn rate by LUCKY COIL.

| id | Name | Color | Effect | Base duration |
| --- | --- | --- | --- | --- |
| `overdrive` | OVERDRIVE | amber | Invulnerable; obstacles and billboards smash on contact for score | 8 s |
| `magnet` | MAGNET | cyan | Cells within 190 u stream to the runner | 10 s |
| `focus` | FOCUS | violet | World time × 0.55 (runner input unaffected) | 6 s |
| `rush` | RUSH | magenta | All score ×2 (stacks multiplicatively with flow) + 12% speed | 10 s |
| `jets` | JET BOOTS | green | Grants one mid-air jump | 12 s |

Rules:

- One powerup active at a time; picking up a new one **replaces** the
  current (with a "SWAPPED" callout). JETS is the exception — it stacks with
  one other (it changes movement, not scoring). Implementation model: two
  slots, `mobility` (JETS) and `power` (everything else).
- FOCUS slows the world and music but not the HUD clock; score ticks follow
  distance travelled, so FOCUS is survivability, not a score lever.
- A powerup expiring flashes its HUD chip 0.5 s before the end.

## 10. Meta: cells, upgrades, missions

**Upgrade Bay** (menu, between runs). Five permanent tracks, five levels
each. Costs per level: **60 / 140 / 300 / 620 / 1200** cells.

| Track | Effect per level |
| --- | --- |
| CAPACITOR | Powerup duration +12% |
| LUCKY COIL | Powerup spawn rate +15% |
| MAGNET CORE | Magnet radius +20% |
| FLOW GRID | Flow points +10% (rounded up per event) |
| HEAD START | Begin runs at 250 m × level (matching speed tier) |

Non-payer promise: cells, upgrades, missions, daily drops, and every powerup
are fully earnable in play; purchases only ever accelerate or remove ads.

**Daily missions.** Three missions per local day, seeded deterministically
from the date (server-time gated like daily rewards). Templates:
`run X m in one run` (800–2600), `collect Y cells in one run` (25–90),
`near-miss N times` (3–12, lifetime of the run), `smash S obstacles` (4–20),
`reach tier T` (3–9). Rewards 40–120 cells scaled by difficulty. Progress
and claim fanfare live on the results screen; a completed-unclaimed mission
badges the menu button.

**Nightly supply drop** = the scaffold's daily-reward track re-skinned:
cells, escalating across a forgiving 7-day cycle (no streak reset).

## 11. Monetization (ship track)

Player-facing copy never says "bucks"; prices render as **RB**.

1. **NEON CORE — 249 RB** (non-consumable, unique). Removes interstitials
   forever, grants a permanent **+25% cells** from every source, and an
   exclusive ion-white trail cosmetic. Comparable: DEADSTOP ad-free 299 RB,
   cosmetic pack 199 RB.
2. **CELL CACHE — 120 RB** (consumable). 500 cells instantly. Comparable:
   KINDRED consumable pack 120 RB.
3. **Rewarded ad — SECOND WIND.** On the results screen, once per run,
   after the player's first completed run: watch a rewarded video to reboot
   at the death point at 60% speed with 2 s invulnerability. Cells stay
   banked either way. Grant only on confirmed SDK success. No-fill fallback:
   the button hides with a one-line explanation; never charge RB as a
   substitute.
4. **Interstitial** — shown only after results are acknowledged, at most
   every 3rd run end, ≥ 300 s apart, ≤ 2 per session and ≤ 6 per day, never
   in the first session, never back-to-back with a rewarded view, removed
   by NEON CORE.

`rundot/shop.config.json` holds both items with `price.type: "bucks"`.
Placement and product registries in `src/systems/monetization/` encode the
policy above; LiveOps flags can fail every surface closed without touching
gameplay.

## 12. Art direction — "Neon Silhouette"

- **Palette.** Sky `#0B1026` → `#1B2242` at the horizon; skyline black
  `#05070F`; neon accents cyan `#3DF5FF`, magenta `#FF3DF0`, amber
  `#FFB347`, violet `#9B5CFF`, green `#52FFA8`; runner body pale `#EAF2FF`.
- **World.** 4 parallax layers (0.12 / 0.3 / 0.55 / 1.0): far tower
  silhouettes with twinkling window grids, mid blocks with neon signage
  glyphs, near roofline, and the gameplay roofline with glowing rim. Light
  rain streaks slant with speed; distant windows flicker.
- **Runner.** Pale silhouette, scarf of magenta that streams and whips with
  velocity; 2–3 ghost afterimages at speed; squash on land, stretch on
  jump.
- **Effects.** Landing dust puffs, edge-save sparks, pickup starbursts,
  near-miss slow-beat (90 ms at 0.35×) + "SWOOSH" text pop, stumble
  hit-stop (70 ms freeze) + shake, OVERDRIVE smash shatter shards, FOCUS
  violet vignette + visible time ripples, RUSH magenta speed lines, death
  tumble + camera overscroll. Reduced-motion strips shake, afterimages, and
  particle counts to 25% — never gameplay timing.
- **UI.** Dark glass panels, neon chip borders, condensed uppercase
  treatment drawn with a procedural bitmap font (no shipped fonts).
  Version string bottom-right of the menu in a safe-area corner.

## 13. Audio

- **Music:** the owner-supplied **"Rooftop Run"** track (`src/audio/assets/
  rooftop-run.mp3`, ~2 min loop) plays under menu and runs alike at a fixed
  **20% music volume**, routed through WebAudio so FOCUS can duck it through
  a low-pass filter. Licensing of the track is the owner's responsibility.
- **SFX stay fully procedural** (filtered noise and tones, no samples):
  jump whoosh, land thud scaled by fall speed, pickup pling
  **pitch-laddered +1 semitone per chained pickup** (resets on stumble),
  near-miss airy swoosh, stumble crash, billboard smash boom, powerup
  stingers, flow tier-up riser, death sub-drop, UI tick/confirm,
  mission-complete fanfare.
- Music/SFX mute persisted; audio unlocks on first gesture; host lifecycle
  pauses/resumes cleanly; ads duck game audio via the presentation-change
  hook.

## 14. FTUE and retention

- First run opens on the runway with a floating "TAP TO JUMP" hint that
  dissolves on the first jump and "HOLD FOR HIGHER" at the first wide gap.
  No modals, no text walls.
- The results screen always shows: distance, best distance (with "NEW BEST"
  stamp), cells earned, mission progress, and one-tap RESTART.
- Return hooks: daily missions, nightly supply drop, and HEAD START as the
  visible long-term unlock. One return reminder notification ("Your nightly
  supply drop is ready", 22 h cadence, consensual + cancellable) reused
  from the scaffold's retention system with new copy.
- Analytics namespace `neonleap`: `run_start`, `run_end` (distance, tier,
  stumbles, cause), `upgrade_buy`, `mission_complete`, `flow_tier`, plus the
  monetization funnel events from the foundation. SECOND WIND reports through
  the portfolio-standard rewarded taxonomy (`ad_requested` / `ad_result` /
  `rewarded_ad_offered` / `rewarded_ad_complete` / `reward_granted`) carrying
  `placementId: "rewarded_second_wind"`, so rewarded funnels compare across
  titles instead of hiding behind a game-specific event name.

## 15. Technical contract

- Forked from `deadstop/` (itself from `scrap-shift/`), not from the
  portrait template: landscape, PixiJS 8 WebGPU-first with WebGL fallback,
  SDK 5.24, Vite 6, strict TS.
- Headless deterministic core in `src/game/sim/` — no Pixi imports; seeded
  by `NoiseRandom`; stepped at a fixed 120 Hz. `npm run simulate` replays
  bot runs asserting: determinism (same seed → same events), fairness
  (every gap clearable by the §7 contract), missions/upgrades arithmetic,
  and save migration.
- `npm run balance` sweeps tiers 0–17 reporting clearable-rate and expected
  cells/min so upgrade costs stay honest against earnings.
- Renderer in `src/game/scene/` consumes sim events (jump, land, pickup,
  near-miss, stumble, smash, powerup, tier-up, death) — effects never feed
  back into the sim.
- Save: `neonleap.save.v1`, versioned with migrations; holds cells,
  upgrades, best distance, missions state, daily track, settings,
  monetization intent (pending purchase), and no-ads entitlement mirror.
- Placeholder `gameId` until `rundot init`; shop/ad surfaces fail closed
  locally and show only in the dev-preview pattern or Playground.
- Verify with `npm run check` (format, lint, version/safe-area/save-schema/
  daily checks, simulate, typecheck, production build) plus
  `node scripts/visual-qa.mjs` screenshot gates.

## 16. Explicitly out of scope (v1)

- Portrait layout, multiplayer, leaderboards, seeded "daily track" events,
  cosmetic shop beyond the NEON CORE trail, text localization beyond the
  single English table the formatter already routes through.
